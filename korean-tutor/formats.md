# Exercise and assessment formats

Choose the format by the claim you need to test. Rotate formats so the learner cannot pass by remembering position, wording, or the previous correction.

## Core formats

| Format | What it measures | Common failure |
|---|---|---|
| Hangul assembly | onset-vowel-final structure | visual copying instead of recall |
| audio discrimination | sound contrast or boundary | speaker/acoustic artifact |
| dictation | sound-to-standard-spelling mapping | unknown vocabulary contaminates the target |
| two-way contextual choice | one grammatical/pragmatic contrast | context is too thin for a unique answer |
| conjugate/build | productive morphology | tests spelling rule but not use |
| complete the dialogue | social and discourse fit | several endings are defensible |
| find and repair | detection plus production | learner assumes every item is broken |
| clean-item judgement | restraint and boundary knowledge | announced clean-item count makes it gameable |
| morpheme segmentation | parsing | over-analysis detached from meaning |
| order chunks | clause structure and information flow | more than one natural order |
| paraphrase | meaning and register control | task accidentally demands new vocabulary |
| evidence question | reading comprehension | correct option from world knowledge |
| role switch | speech level/honorific choice | relationship is underspecified |
| summary | hierarchy and discourse | evaluates writing range more than reading |

## Construction rules

- Use the learner's vocabulary, goals, and actual errors where available.
- Change the lexical surface of anything seen before.
- Test one intended mechanism per narrow item; a free-production task may expose several, but score them separately.
- Include clean items after H0/early K1. A test where everything is wrong trains indiscriminate correction.
- Put a boundary item beside every new rule.
- Ask for a reason where discourse, register, or inference matters.
- Do not print the key with an active test.
- Number items so the learner can answer compactly.
- Stop after delivering an interactive set and wait for the learner.

## Korean context sufficiency

Before using a particle, ending, honorific, or register item, check that the prompt supplies enough information:

- previous discourse for topic/focus;
- speaker/listener/subject relationship;
- formality and medium: speech, chat, email, notice, essay;
- intended speech act;
- time/aspect context;
- whether omission is licensed.

If two competent speakers could choose differently for different inferred contexts, either add context or accept both with an explanation.

## Clean items

Suggested ratios:

- H0: none until the visual or auditory category is understood;
- K1: 0-1 per short set;
- K2: 1-2;
- K3-K4: 20-35%;
- K5-K6+: 50-70%, because most advanced production is acceptable and the task is often appropriacy.

Track unnecessary changes separately as hypercorrection or over-application. Raise the clean ratio after a new rule attracts false positives.

## Audio items

- Normalize volume across options and speakers.
- Do not let one option contain background noise or duration cues absent from the others.
- Use known vocabulary when measuring a sound; use controlled sound when measuring a word.
- For listening comprehension, keep transcript, key, and evidence span privately; reveal after submission.
- Rotate voice and surface details on retest.

## Reading items

Write the key from text evidence before writing distractors. Distractors should correspond to plausible mechanisms: wrong referent, reversed connective, over-inference, detail/main-idea confusion, lexical near-neighbour. Do not make the distractor wrong only by an obscure fact outside the text.

For inference, state the standard: entailed, strongly supported, merely plausible, or contradicted. Do not treat "could be true" as text support.

## Vocabulary items

Test several directions:

- context -> word;
- word -> paraphrase;
- collocation completion;
- near-neighbour choice with explanation;
- Hanja-family inference;
- register/genre fit;
- productive use.

Avoid grading exact L1 wording when the Korean meaning is correct.

## Scoring and item defects

Write acceptable answers before the learner sits the test. Normalize harmless spacing or punctuation only when that feature is not the target. When spacing, spelling, or particle choice is the target, do not normalize it away.

On dispute:

1. reread the item without looking at the key;
2. identify the missing context or alternative analysis;
3. rescore if defensible;
4. log an instrument defect;
5. exclude the item from learner pattern counts.

For any larger bank, run an independent blind key check: student view without answers; solver response with confidence and alternative answers; comparison to key; revision of ambiguous or unnatural Korean. High answer agreement does not prove the item is unambiguous.

## Result report

Report:

1. score with slice, for example `7/9 - K2 particle-context set`;
2. item-level misses;
3. smallest verified mechanism;
4. clean-item behavior;
5. what remains a hypothesis and the next discriminating check;
6. one next action;
7. state update and delayed transfer date.

Do not turn a ten-item round into a global Korean level.
